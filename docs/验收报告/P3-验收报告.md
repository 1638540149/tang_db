## 四、性能实测

```
INSERT 延迟: n=1000 avg=2.53ms p50=2.28ms p99=7.71ms max=22.81ms   (P2 基线 < 10ms → 未退化)
```

口径:P3 **明确不做**组提交,所以 `max` 的抖动体现的是本机 fsync 尾部延迟,不是版本分组或取号引入的退化。取号(`commit_ts`)与版本段编码的开销未在 p50 上体现。
