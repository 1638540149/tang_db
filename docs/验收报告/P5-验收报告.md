**探针自身判错的三条(已排除,不是产品缺陷)**

1. `SELECT ABS(-5), ROUND(3.6)...` → 1064:这是**无 FROM 的表达式投影**,按规约边界 39 本期只支持字面量列表,表达式归 P5 之后的表达式体系;带 `FROM` 时(上表)全部正常。
2. `SELECT YEAR('2024-02-29')...` → 同理,无 FROM。
3. `CREATE INDEX ... ON p5j (doc)` 成功:该探针把 `doc` 建成了 `VARCHAR` 而非 `JSON`;改用 `JSON` 列后按 FR-611 正确报 1235。
