对照所有者测试记录里那三条报错:
- 第 2/21~27 条「无法识别的字符 '\`'」→ **消失**,反引号全套可用(建表/插入/查询/更新/删除/`DESC`/表名)。
- 第 4 条「期望 列名列表的 '('」→ **消失**,`insert into student values(...)` 可用。
- 第 1 条 `show Databases` → **可用**,输出 `default`。

## 三、测试记录 31 条的逐条对账

| 记录条目 | 判定 | 处置 |
|---|---|---|
| 1 `SHOW DATABASES` | 真缺口 | **P2.1 已补**(FR-200~203) |
| 2、21~27 反引号 | 真缺口 | **P2.1 已补**(FR-180~187) |
| 3 `ALTER TABLE` | 规约外 | 归 P4 之后(§2.2) |
| 4 INSERT 省略列名 | 真缺口 | **P2.1 已补**(FR-190~193) |
| 5~14 `NOT` / `NOT IN` / `BETWEEN` / `LIKE` / `IS [NOT] NULL` | 规约缺口 | 归属**已定:P5**(K37、§6);本期不做 |

| 28 `day` 当列名 | 非 bug | 当前关键字表里没有 `day` |
| 29 `LIMIT 2` 正常 / `ORDER BY`、`OFFSET`、`LIMIT 1,2` | 部分规约外 | `ORDER BY` 归 P5;`OFFSET`、`LIMIT m,n` 未在本期(§2.2) |
