## 2. 实现顺序(六步,每步自证)

| 步 | 内容 | 自证 |

| 1 | **先打点,不许先改**:在 `SearchVectorIndex` 里分五段计时(候选准备 / 图搜索 / memtable 暴力 / 候选归并 / 回表前的数据准备),`SET vector_profile = ON` 时打印,默认关闭 | 同一查询开打点跑一次,贴出五段耗时 |

## 3. 硬约束

- **门限不动**:SC-431 ≤100ms、SC-427 ≤2×,一个数字都不许改。
- **磁盘格式不动**:`format_version` 仍 3、图段布局不变、老目录照旧可启动。
- **语义不动**:`pushdown` / `vector_exact` / `vector_path` 三开关行为不变;三路结果逐行一致。
- **依赖红线**:BE 只用 grpc + protobuf;FE 不引任何第三方库(缓存、LRU 都自己写)。
- **边界不可穿透**:BE 不出现表名/列名/类型名;FE 不写 BE 数据目录。
- 不 `git commit`、不改 `specs/`、不写 `docs/验收报告`。

## 4. 工作方式(踩过的坑)

- **禁止派子代理**;禁止 `nohup` / `disown` / 裸 `&` 起服务(会把 bash 工具卡死);起服务只用仓库脚本;单条命令超 90 秒换写法。
- **环境独占**:同一时刻只跑一个脚本;跑前确认没有残留 `be.exe` / `tangdb.fed.Fed`。
- **IDE 可能抢 `fe/target/classes`**:看到 `ClassNotFoundException: com.wangyu.tangdb.fed.Fed` 就等 10 秒重试,别改代码去"修"。
- 每步做完立刻:`cd be && go build ./... && go vet ./... && go test ./...` 与 `cd fe && mvn.cmd test`。
- **跑性能必须安静机**:跑 `p7-perf.sh` 前确认没有别的脚本/编译在跑,三次取中位数。
