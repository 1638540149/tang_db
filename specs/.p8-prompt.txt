## 1. 技术栈硬性要求(所有者指定)

- 控制台前端:**Vue 3 + Element Plus + Vite**;源码在 `console/`,构建产物 `console/dist/` **要提交入库**。
- 控制台后端:**FE 内置 JDK `com.sun.net.httpserver`**,**禁止**引入 Spring / Javalin / Vert.x / Netty HTTP 等任何 Java Web 框架。
- 监控:**禁止**引入 Prometheus Java 客户端或任何指标库,文本格式手写。
- 前端依赖只允许 `vue`、`element-plus`、`vite`(及其必需的构建期依赖)。npm 已配 npmmirror 源。
- 若 `npm install` 超过 10 分钟没成功:先把后端 API 与 `dist/` 占位页面做完,把前端构建写进 README 的"待补",**不要卡在这里**。

## 3. 硬约束

- **依赖红线**:BE 只允许 grpc + protobuf;FE 不得新增任何第三方 Java 库(HTTP 服务、JSON 序列化、指标全部用 JDK 自带;JSON 手写或复用现有工具)。
- **边界不可穿透**:FE 不读写 BE 数据目录(备份由 BE 执行,FE 只下发命令);BE 不出现表名/列名/SQL。
- **先日志后数据**不变;段文件不可变不变;`format_version` 仍为 3(备份不改它)。
- 系统表新增 10、11 必须登记进 `SystemTables.REGISTERED_IDS`,`next_table_id` 下限不变。
- 门限不许改;`specs/`、`docs/` 不许改;不 `git commit`。

## 4. 工作方式(踩过的坑)

- **禁止派子代理**;禁止 `nohup` / `disown` / 裸 `&` 起服务(会把 bash 工具卡死);起服务只用仓库脚本;单条命令超 90 秒换写法。
- 每个步骤做完立刻 `cd fe && mvn.cmd test` 与 `cd be && go build ./... && go vet ./... && go test ./...`。
- **IDE 会抢 `fe/target/classes`**:遇到 `ClassNotFoundException: com.wangyu.tangdb.fed.Fed` 等 10 秒重试,不要改代码去"修"。
- 独占环境:同一时刻只跑一个脚本;跑前确认无残留 `be.exe` / `tangdb.fed.Fed`。
- 控制台端口 8080 与 MySQL 3406 冲突时改 `console_port`,不要强占。

## 5. 测试优先级(所有者明确要求)

1. **先把 P8 自己做的功能测通**(协议探测清单、指标、慢查询、备份恢复、控制台 API 冒烟),确保没 bug;
2. 时间够再跑全量回归(`p3`/`p4`/`p5`/`p6`/`p6.1`/`p7`/`p7.1` 逐个单跑);
3. 跑不完就**明说哪几项没跑**,不许写"应该没问题"。
